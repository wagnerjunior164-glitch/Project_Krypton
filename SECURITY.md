# Security Policy

## Scope

This repository is the public distribution of ProjectKrypton. Do not disclose private infrastructure details, credentials, tokens, session data, or other sensitive information in issues or pull requests.

## Reporting a vulnerability

Please do not report suspected vulnerabilities through a public issue. Use the private security reporting mechanism provided by GitHub for this repository, when enabled.

If private reporting is not enabled, do not include exploit details, credentials, or sensitive data in a public issue. The repository maintainer should enable an appropriate private reporting channel before asking for sensitive vulnerability details.

## Supported versions

The currently published public tree is the initial ProjectKrypton publication and has completed the official certification scope of Parts 01–09.

Formal version/release support entries will be added as public GitHub Releases are created. The absence of a GitHub Release entry does not mean that the public repository is unpublished; it means only that the GitHub Release mechanism has not yet been populated.

## Publication status

The repository is **public and published**. The initial public candidate was certified through Parts 01–09 and then published to `main`.

The official publication status, certification scope, private/public development model and post-publication rules are documented in `docs/ProjectKrypton/PUBLICATION-STATUS.md`.

The certification Part 10 remains suspended for future reassessment and is not a current publication blocker.
