# Security Policy

## Scope

This repository is being prepared as the public distribution of ProjectKrypton. Do not disclose private infrastructure details, credentials, tokens, session data, or other sensitive information in issues or pull requests.

## Reporting a vulnerability

Please do not report suspected vulnerabilities through a public issue. Use the private security reporting mechanism provided by GitHub for this repository, when enabled.

If private reporting is not yet enabled, do not include exploit details, credentials, or sensitive data in a public issue. The repository maintainer will enable the appropriate reporting channel before the public release is considered complete.

## Supported versions

The public release and supported versions will be documented here after the publication gate is approved.

## Publication status

The repository is currently in preparation. Publication is blocked until the public-tree audit, sanitization, independent rescan, functional validation, and final documentation approval are complete.
