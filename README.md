# ProjectKrypton

ProjectKrypton is a modular software ecosystem composed of independent projects and supporting documentation.

This repository is the public distribution tree. It is intentionally maintained with a new Git history and does not expose the history of the private development repository.

## Status

The public tree is currently under preparation. The source code, tests, documentation, CI configuration, dependencies, and examples are being reviewed before the first public release.
